# 🎓 Student Grade Management System (Python)

A simple **Student Grade Management System** built with Python that allows users to manage student records, calculate grades, and view academic performance. This project is ideal for Python beginners who want to practice file handling, functions, loops, dictionaries, and object-oriented programming (if applicable).

## 📌 Features

- ➕ Add new student records
- 📋 View all students
- ✏️ Update student information
- ❌ Delete student records
- 🔍 Search students by ID or name
- 🧮 Calculate total marks, percentage, and grade
- 🏆 Display pass/fail status
- 💾 Save data to a file (optional)
- 📂 Load saved student data automatically

## 🛠️ Technologies Used

- Python 3.x
- File Handling (CSV/JSON/Text)
- Functions
- Loops
- Dictionaries / Lists
- Object-Oriented Programming (Optional)
